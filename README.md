# Mayank Goyal — Portfolio

A personal portfolio built with React, TypeScript, Vite, GSAP, and Three.js. It highlights my full-stack and AI projects, skills, education, and contact details.

## Run locally

```sh
npm ci
npm run dev
```

Create a production build with `npm run build`.

## GitHub Pages

Push to `main` to build and deploy the site with GitHub Actions. The deployment workflow is in `.github/workflows/deploy.yml`.
